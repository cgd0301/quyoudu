## 三、必须区分的事项

1. **官方全国要求**：主题、十大方向、赛程、团队上限、原创要求、提交流程与截止时间（GH01—GH04）。
2. **官方未公开事项**：章节模板、页数/字数、文件格式与大小、评分维度与权重。不得用其他高校通知或创业比赛模板冒充。
3. **团队自定标准**：主文结构（摘要 + 八章 + 结论 + 产品建议 + 附录 A—E）、500 字概述/产品建议上限、图表数量、测试门禁。这些是团队自定的工程质量标准，不是工行杯官方规则。
4. **项目事实**：本地成稿、测试结果、问卷统计。它们不是“已提交”“已获奖”“已合作”。
