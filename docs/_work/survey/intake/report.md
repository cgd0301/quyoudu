## 九、处置建议

1. 从原始表单或工作簿重新导出 **XLSX** 或 **UTF-8 CSV**；不要使用 Excel for the web 的旧版“下载为 CSV”。
2. 确认导出件包含题干与选项原文；若线上表单与 `docs/_work/survey/schema.json` 不是同一套题目，提供两版题面与字段映射。
3. 确认导出件包含应答编号、提交时间与作答时长字段，用于去重、有效性与时长校验。
4. 检查开放题是否含个人信息；如有，先脱敏再分析，原文不进入报告或项目书。
5. 把可读导出件放到 `docs/_work/survey/raw/responses.csv`（不入库），运行 `pnpm survey:intake` 与 `pnpm survey:report`。
