## C. 核心发现

> 以下比例均为**这批受访者中**的比例；不写“全国青年”“大多数用户”。证据强度只描述样本内一致性，不代表总体。

### C1 消费场景：跨城观演只是少数场景

| 过去 12 个月的消费经历 | 人数/分母 | 比例 |
| --- | --- | --- |
| 旅行 | 22/30 | 73.3% |
| 购买较昂贵的电子产品或其他商品 | 19/30 | 63.3% |
| **跨城演唱会、音乐节或现场演出** | **9/30** | **30.0%** |
| 跨城体育赛事或大型活动 | 1/30 | 3.3% |
| 以上皆无 | 4/30 | 13.3% |

**判断**：样本中的大额/多笔消费主要是旅行与电子产品；跨城观演是少数（30%）。这不否定跨城观演场景存在，但**不支持把它当作这批受访者的主导场景**。把产品定位收窄为“跨城观演”会丢掉样本中更大的旅行/电子产品消费规划需求。

**证据强度**：样本内中等（n=30，单一多选题）。**不能支持**：全国青年的跨城观演比例、跨城观演市场规模。

### C2 资金规划问题：普遍存在，但“付款日错配”只是少数

| 过去 12 个月遇到的资金规划问题 | 人数/分母 | 比例 |
| --- | --- | --- |
| 担心消费影响日常生活开支 | 11/30 | 36.7% |
| 总费用超出预算 | 9/30 | 30.0% |
| 忘记或低估后续费用 | 8/30 | 26.7% |
| 难以比较不同方案的总成本 | 6/30 | 20.0% |
| 因不确定是否负担得起而推迟或放弃计划 | 6/30 | 20.0% |
| **总体资金足够，但某个付款日期前可用资金不足** | **4/30** | **13.3%** |
| 以上均没有 | 8/30 | 26.7% |

- 至少报告 1 项资金问题的：**22/30（73.3%）**；8/30（26.7%）表示“以上均没有”。
- 最常被选的是“担心影响日常生活开支”（36.7%）与“总费用超预算”（30.0%）。
- 项目假设中的“付款日错配”原文选项只被 **4/30（13.3%）** 选中；它不是这批受访者的主要问题形态。

**判断**：资金规划痛点在样本中普遍（73.3%），但**具体机制与项目最初的三条假设不完全一致**：更常见的是总额与日常生活压力，而不是“钱够、只是付款日不够”。

**证据强度**：样本内较强（问题普遍性）；具体机制为弱到中等（单个选项 13.3%）。**不能支持**：总体患病率、问题严重程度排序。

### C3 影响：焦虑与压缩其他开支最常见

| 问题造成的影响 | 人数/分母 | 比例 |
| --- | --- | --- |
| 感到焦虑或犹豫 | 17/30 | 56.7% |
| 减少其他开支 | 11/30 | 36.7% |
| 动用原本希望保留的储备资金 | 8/30 | 26.7% |
| 花费额外时间计算和核对 | 7/30 | 23.3% |
| 临时修改或取消计划 | 6/30 | 20.0% |
| 没有明显影响 | 5/30 | 16.7% |
| 没有遇到相关问题 | 3/30 | 10.0% |

- 至少报告 1 项影响的：**22/30（73.3%）**。
- “感到焦虑或犹豫”是最高频影响（56.7%），其次是“减少其他开支”（36.7%）。
- “动用储备资金”（26.7%）比“无法区分可消费资金与必要储备”（10.0%，见 C4）更常见：**行为上的储备侵蚀比认知上的重复计算更普遍**。

**证据强度**：样本内中等偏强（焦虑与压缩开支过半数）。**不能支持**：焦虑程度、因果方向、长期福利影响。

### C4 现有方式的不足：重算与手工输入最突出

| 现有资金规划方式的不足 | 人数/分母 | 比例 |
| --- | --- | --- |
| 计划变化时需要重新计算 | 13/30 | 43.3% |
| 需要手动收集和输入太多资料 | 9/30 | 30.0% |
| 难以比较多个完整消费方案 | 8/30 | 26.7% |
| 没有固定的规划方式 | 7/30 | 23.3% |
| 难以掌握每笔费用的付款日期 | 6/30 | 20.0% |
| 目前的方法已经足够好 | 4/30 | 13.3% |
| 无法清楚区分可消费资金与必要储备 | 3/30 | 10.0% |

- 至少报告 1 项不足的：**26/30（86.7%）**。
- **“计划变化时需要重新计算”是第一大不足（43.3%）**；“手工输入太多”（30.0%）与“难以比较完整方案”（26.7%）次之。
- “目前的方法已经足够好”只有 4/30（13.3%），是明确的少数反证，但不能忽略。

**判断**：产品的“比较完整方案 + 付款时间轴 + 变更后快速重算”方向与样本中的主要不足一致；“区分可消费资金与必要储备”这一具体机制只有 3/30 直接支持。

**证据强度**：样本内较强（86.7% 至少一项不足）。**不能支持**：这些不足在总体中的比例、用户愿意为修复它付多少钱。

### C5 试用意愿：70% 落在前两档，但只是自报意愿

| 未来 3 个月使用可能性 | 人数/分母 | 比例 |
| --- | --- | --- |
| 一定会尝试 | 8/30 | 26.7% |
| 很可能会尝试 | 13/30 | 43.3% |
| 不确定 | 7/30 | 23.3% |
| 不太可能 | 1/30 | 3.3% |
| 一定不会 | 1/30 | 3.3% |

- 前两档合计 **21/30（70.0%）**；明确负面 **2/30（6.7%）**；不确定 7/30（23.3%）。

**判断**：在这批受访者中，试用意愿偏正向；但这是**免费试用**情境下的自报意愿，不等于实际使用、留存或付费。

**证据强度**：样本内中等（70% 前两档）。**不能支持**：实际转化率、留存率、付费率。

### C6 功能偏好：多方案比较第一，付款时间轴第二

| 功能 | 人数/分母 | 比例 |
| --- | --- | --- |
| 多方案比较：比较不同门票、交通、住宿组合的费用与付款安排 | 13/30 | 43.3% |
| 付款时间轴：查看每笔费用的付款日期及对应资金需求 | 11/30 | 36.7% |
| 必要资金保护：保留日常生活费及指定储备资金 | 9/30 | 30.0% |
| 资金缺口预警：提前发现某个时间点可能出现的资金不足 | 9/30 | 30.0% |
| 行动清单：提示下一步需要确认或处理的事项 | 8/30 | 26.7% |
| 情景模拟：测试收入延迟或费用增加后的影响 | 2/30 | 6.7% |
| 不确定费用提示：标记尚未确认的费用及其影响 | 2/30 | 6.7% |
| 以上均没有明显吸引力 | 4/30 | 13.3% |

- 至少选择 1 项功能的：**26/30（86.7%）**；4/30（13.3%）表示没有明显吸引力。
- 第一优先是**多方案比较**（43.3%），其次是**付款时间轴**（36.7%）；“必要资金保护”和“资金缺口预警”并列 30.0%。
- “情景模拟”和“不确定费用提示”只有 2/30，**不应因为它们在产品里已实现就当作优先功能**。

**证据强度**：样本内中等（多选题，n=30）。**不能支持**：功能使用率、付费意愿与功能优先级的因果关系。

### C7 顾虑：隐私第一，输入负担与“过于乐观”并列第二

| 使用这类工具时最在意/担心 | 人数/分母 | 比例 |
| --- | --- | --- |
| 个人财务信息的隐私与安全 | 16/30 | 53.3% |
| 是否遗漏费用或给出过于乐观的判断 | 9/30 | 30.0% |
| 输入资料是否太麻烦 | 9/30 | 30.0% |
| 计算结果是否准确 | 6/30 | 20.0% |
| 结果是否容易理解 | 3/30 | 10.0% |
| 不希望工具影响自己的消费决定 | 3/30 | 10.0% |
| 没有明显担忧 | 2/30 | 6.7% |

- 至少报告 1 项顾虑的：**28/30（93.3%）**；只有 2/30 说没有明显担忧。
- **隐私与安全是第一顾虑（53.3%）**；“遗漏费用/过于乐观”（30.0%）与“输入太麻烦”（30.0%）并列第二。

**判断**：隐私不是“加分项”，而是采用前置条件；产品必须做到数据最小化、可解释、明确不确定性，且不能让输入步骤本身成为放弃点。

**证据强度**：样本内较强（隐私过半数）。**不能支持**：用户愿意为隐私付出多少成本、具体隐私机制偏好。

### C8 付费方式：只有 26.7% 选择任何付费形式，且没有价格信息

| 最能接受的使用/付费方式 | 人数/分母 | 比例 |
| --- | --- | --- |
| 只使用免费版本，不愿付费 | 12/30 | 40.0% |
| 由银行、学校或其他机构提供免费服务 | 5/30 | 16.7% |
| 为一次完整的消费计划支付少量费用 | 5/30 | 16.7% |
| 暂时无法判断 | 4/30 | 13.3% |
| 为持续使用支付月费 | 2/30 | 6.7% |
| 视实际功能和效果而定 | 1/30 | 3.3% |
| 为高级功能支付一次性费用 | 1/30 | 3.3% |

- **任何付费形式合计 8/30（26.7%）**：按次 5、月费 2、高级功能一次性 1。
- **不打算个人付费 17/30（56.7%）**：只用免费版 12 + 希望机构提供免费 5。
- 未决定 4/30（13.3%）；条件性 1/30（3.3%，选“视实际功能和效果而定”）。
- **分类覆盖核对**：该题是单选，7 个选项互斥，七类人数合计 30/30。上一轮的四类汇总（任何付费 8 + 只用免费 12 + 机构免费 5 + 未定 4）合计 29/30，**缺的第 1 人就是“视实际功能和效果而定”**；这是汇总口径漏项，不是数据缺失，也不是某人未作答。
- **问卷没有给任何具体价格**（没有 1 元/5 元/10 元等档位），因此不能推出价格、ARPU、付费率或收入。

**判断**：按次付费是样本中相对最容易被接受的付费形式（5/30），但远未过半数；多数人倾向免费或机构付费。**银行/学校提供免费服务**有 5/30 的偏好信号，但这只是用户偏好，不是合作意向或采购承诺。

**证据强度**：样本内中等偏弱（付费形式偏好，非真实支付）。**不能支持**：具体价格、付费转化率、收入、LTV、CAC。

### C9 目标人群内部差异（探索性，不作结论）

| 子组 | n | 至少 1 项资金问题 | 焦虑/犹豫 | 试用前两档 | 任何付费形式 |
| --- | --- | --- | --- | --- | --- |
| 有跨城观演经历 | 9 | 6/9（66.7%） | 5/9（55.6%） | 6/9（66.7%） | 1/9（11.1%） |
| 无跨城观演经历 | 21 | 16/21（76.2%） | 12/21（57.1%） | 15/21（71.4%） | 7/21（33.3%） |

**判断**：在这批样本中，有跨城观演经历的人并没有表现出更高的资金问题比例或更强的试用意愿；付费形式偏好反而更低（1/9）。子组 n 很小，不能做统计检验，也不能据此否定跨城场景；它只说明**“跨城观演”不是这批样本中痛点的必要条件**。

## D. 对产品的影响

### D1 受到初步支持的产品假设

| 假设 | 证据 | 强度 |
| --- | --- | --- |
| 用户需要“比较完整方案”，而不只是逐项低价 | Q6 难以比较完整方案 8/30；Q8 多方案比较 13/30（第一） | 中等（样本内） |
| 付款时间轴/缺口预警有价值 | Q8 时间轴 11/30；缺口预警 9/30；Q6 难以掌握付款日期 6/30 | 中等偏弱 |
| 资金保护/储备区分有需求 | Q8 必要资金保护 9/30；Q5 动用储备 8/30 | 中等偏弱 |
| 变更后快速重算有价值 | Q6 计划变化需重算 13/30（第一不足） | 中等（样本内） |
| 隐私与准确性是采用前提 | Q9 隐私 16/30；过于乐观 9/30；准确性 6/30 | 较强（样本内） |

### D2 受到反证或需要缩小范围的假设

| 原假设 | 本轮证据 | 处理 |
| --- | --- | --- |
| 目标用户主要是“跨城观演”人群 | 跨城观演 9/30（30%），低于旅行 73.3% 与电子产品 63.3% | **缩小范围**：将“跨城观演”作为切入场景之一，不当作样本中的主导场景；项目书应同时说明旅行/大额消费场景 |
| 核心痛点是“付款日错配”（钱够但某天不够） | 该选项 4/30（13.3%）；更常见的是担心影响生活（36.7%）与超预算（30%） | **降级**：付款日错配是少数机制，不能作为唯一核心假设 |
| 核心痛点是“同一笔钱重复计算” | 无法区分可消费资金与必要储备 3/30（10%）；动用储备 8/30（26.7%） | **改写**：把“重复计算”改写为“储备被侵蚀/可消费与必要资金边界不清”，后者证据更强 |
| 逐项拼价导致整体不可行 | 难以比较完整方案 8/30；难以比较总成本 6/30；临时修改/取消 6/30 | **部分支持**：支持“比较与重算”痛点，不支持“不可行”这一具体后果的普遍性 |

### D3 功能优先级建议（基于样本，不等于最终排期）

1. **多方案比较**（13/30，第一）与**付款时间轴**（11/30，第二）：保留为核心。
2. **必要资金保护 / 资金缺口预警**（各 9/30）：保留，但需要在文案上证明“保护”不是限制消费。
3. **行动清单**（8/30）：保留为辅助。
4. **情景模拟 / 不确定费用提示**（各 2/30）：样本中优先级最低；不因已实现而前置，先做可用性验证。
5. **隐私与可解释性**：不是功能列表项，而是所有功能的前置条件（53.3% 提及隐私）。

### D4 尚未获得足够证据的产品假设

- 用户是否会在真实场景中完成一次完整规划（而不是只在问卷中表示愿意）。
- 用户是否愿意持续使用、是否留存。
- “暂无法判断”的保守输出是否会被接受（本轮未测）。
- 用户是否愿意为“事前可行性”多花一次操作（本轮未测）。
- 跨城观演用户与一般大额消费用户的需求差异（子组 n 太小）。

## E. 对商业模式的影响

| 商业问题 | 本轮能回答什么 | 仍不能回答什么 |
| --- | --- | --- |
| 谁可能是目标用户 | 香港/内地学生为主，18—20 岁占 73.3%；但这是便利样本 | 总体用户画像、规模、地域结构 |
| 用户是否有明确问题 | 73.3% 至少报告 1 项资金问题；焦虑 56.7% | 问题严重度、支付意愿、问题频率 |
| 现有解决方式 | 86.7% 至少报告 1 项不足；重算 43.3%、手工 30% | 现有工具的实际使用率与替代成本 |
| 是否对产品感兴趣 | 70.0% 试用前两档 | 实际试用、留存、转化 |
| 是否接受收费方式 | 26.7% 任何付费形式；按次 16.7% 最高；56.7% 不打算个人付费 | **具体价格**、支付周期、成交率、退款率 |
| 银行/机构渠道 | 16.7% 希望机构提供免费服务 | 机构采购意愿、合作条件、B2B2C 收入 |
| 获客成本/留存/频次 | 未测量 | CAC、留存、使用频次、LTV |
| 单位经济/盈亏平衡 | 未测量 | 贡献额、固定成本、盈亏平衡点 |

**结论**：本轮问卷把“问题是否存在”“功能偏好”“付费方式偏好”推进了一步，但**没有**提供价格、真实支付、CAC、留存或使用频次。因此：

- 可以写“在这批受访者中，26.7% 选择某种付费形式，按次付费是相对最高的一项”；
- **不能**写“用户愿意支付 X 元”“付费率 X%”“收入/利润/盈亏平衡 X”；
- 单位经济与盈亏平衡仍保持“无法计算”。

## F. 未解决问题与下一步验证

| 优先级 | 待验证问题 | 现有证据 | 缺失证据 | 建议方法 | 是否阻塞商业结论 |
| --- | --- | --- | --- | --- | --- |
| 高 | 具体价格与价格弹性 | 只有付费方式偏好 | 价格点、成交、退款 | 离散选择/价格测试（含具体价格与周期），样本量另行设计 | 是 |
| 高 | 真实使用与留存 | 70% 自报试用意愿 | 实际完成、复访、留存 | 20—30 人行为试点，记录完成率、放弃点、7/30 日留存 | 是 |

## G. 反证与少数意见（必须保留）

- **4/30（13.3%）认为“目前的方法已经足够好”**：说明替代动机并非普遍。
- **4/30（13.3%）认为列出的功能“没有明显吸引力”**。
- **12/30（40.0%）只使用免费版本，不愿付费**；**17/30（56.7%）不打算个人付费**。
- **2/30（6.7%）明确表示不太可能/一定不会尝试**。
- **8/30（26.7%）表示过去 12 个月没有资金规划问题**。
- **跨城观演只有 9/30（30.0%）**，且该子组的试用意愿与付费偏好不高于其他样本；这直接挑战“跨城观演是核心场景”的定位。
- **“付款日错配”只有 4/30（13.3%）**；**“无法区分可消费资金与必要储备”只有 3/30（10.0%）**。项目最初的两条机制假设在本样本中是少数。

这些反证不否定产品价值，但要求项目书**缩小结论范围**，不能写“用户普遍需要”“跨城观演是刚需”。
