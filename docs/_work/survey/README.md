# 问卷数据规范与隐私边界

本目录只放**问卷方法与分析口径**，以及（将来）由项目负责人正式收集的去标识化结果。
当前状态：**问卷尚未发放，仓库中没有任何真实答卷**。因此本目录下不存在、也不允许存在统计结果。

## 一、客户证据的唯一来源

按本轮研究纪律，客户需求、痛点频率、使用偏好、产品意向与付费意愿的实证结论**只能来自问卷**。以下内容一律不得充当客户证据：

- 访谈、社交平台评论、论坛帖子、产品评价、他人故事（本轮不开展访谈，也不采集这些内容）；
- 团队成员的个人经历（只能作场景说明，标注"团队成员亲历"，不作为样本）；
- 公开市场规模、平台用户量、竞品功能（属公开二手资料，另见 `docs/sources.md` 文末核验记录）；
- 项目内部的自动化测试、模拟数据与对拍结果（属技术证据）；
- AI 生成的用户画像、虚拟用户故事、"典型消费者"。

## 二、文件与版本

| 文件 | 是否入库 | 说明 |
| --- | --- | --- |
| `questionnaire.md` | 入库 | 问卷题目与发放口径（设计稿，不是结果） |
| `schema.json` | 入库 | 字段、题型、取值与清洗规则；分析脚本的唯一输入契约 |
| `analysis_template.md` | 入库 | 结果录入模板（空表，标注"待填"） |
| `report.md` | 入库 | 由 `pnpm survey:report` 生成；无输入时只写"未运行（缺少输入）" |
| `raw/responses.csv` | **不入库**（`.gitignore`） | 原始答卷；含潜在可识别信息，只在本地保存 |
| `raw/metadata.json` | **不入库** | 采集时间范围、渠道、样本来源说明 |

数据版本规则：每次收集或修订原始答卷，都要在 `raw/metadata.json` 里递增 `data_version`，并记录采集起止日期、发放渠道、目标样本量与回收量。`report.md` 头部会写出版本号与原始文件的 SHA-256，任何统计都能追溯到具体一份文件。

## 三、隐私与数据最小化

1. 原始答卷**不提交到仓库**，也不写入项目书、PPT、README 或任何 Git 提交。
2. 问卷不收集姓名、手机号、邮箱、学号、身份证号、银行卡、账户信息、精确住址。
3. `respondent_id` 只用于去重，取随机串，不与任何身份信息关联；分析输出只出现汇总值。
4. 开放题原文**不进入** `report.md`，只统计条数；若要引用原句，必须去标识化并由项目负责人确认。
5. 有效样本 < 30 时，`report.md` 自动加"样本量不足，不用于推广结论"的提示。
6. 涉及个人信息的分析（如消费金额）只报告分档分布，不报告可反推个人的极值。

## 四、清洗与统计口径（脚本强制）

| 场景 | 口径 |
| --- | --- |
| 重复答卷 | 按 `respondent_id` 去重，保留 `submitted_at` 最晚的一条；其余计为"重复，剔除" |
| 作答时长 | 小于 `schema.json` 中 `min_duration_seconds` 的答卷计为"无效：时长达短" |
| 注意力检查 | 指定题的答案不等于期望值时计为"无效：注意力检查未通过" |
| 必答题缺失 | `required` 中的题为空时计为"无效：必答缺失" |
| 非必答跳题 | 保留该答卷，该题计为"缺失"，分母为"回答了该题的有效答卷数" |
| 单选题 | 百分比分母 = 该题有效回答数，四舍五入到 1 位小数 |
| 多选题 | 百分比分母 = 有效答卷数（各选项之和可以超过 100%），并给出平均选择项数 |
| 量表题 | 报告 n、均值、中位数与各档分布；不把均值当"满意度结论" |
| 开放题 | 只统计条数，不做自动编码，不改写原意 |
| 无效答卷 | 不计入任何分母，也不为提高样本量而计入有效样本 |

## 五、结论边界

- 问卷只能说明**这批受访者**的回答，不能直接外推为全市场比例；项目书引用时必须同时写出样本量、采集时间与抽样方式。
- 自报"愿意尝试"不等于实际使用；自报价格区间不等于真实购买转化；报告中不得把二者混写。
- 本轮不做统计推断（显著性检验、相关分析）；样本量满足后再决定是否需要，且必须写明检验方法。

## 六、复现流程

```powershell
# 1. 把去标识化答卷放到本地（不入库）
#    docs/_work/survey/raw/responses.csv
# 2. 生成统计
pnpm survey:report
# 3. 产出
#    docs/_work/survey/report.md（统计结果，含版本与 SHA-256）
```

没有 `raw/responses.csv` 时，脚本只写"未运行（缺少输入）"，退出码 0，**不产生任何数字**。
