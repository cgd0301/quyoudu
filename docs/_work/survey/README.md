# 问卷数据规范、清洗口径与当前状态

本目录保存**实际投放问卷**的字段契约、脱敏分析数据、统计结果与证据解释。原始 XLSX 不入库；脱敏分析数据可入库并用于复算。

## 当前状态（2026-10-19）

- 线上表单收到 **30 位独立受访者（n=30，团队确认口径）** 的作答，全部 10 题作答，无缺失；导出件无应答编号，本轮不做身份去重。
- 原始 XLSX：`趣有度｜青年消费计划与资金安排调查.xlsx`（SHA-256 `06d6b633…02670a`，不入库）。
- 脱敏分析数据：`analysis/responses.csv`（删除邮箱、姓名、精确时间戳；R01—R30 只是行号重命名）。
- 统计附表：`report.md`（逐题人数、分母、百分比、单选题分组合计）；研究发现：`findings.md`（证据强度、局限、反证）。
- 样本：香港 16 / 内地 14；18—20 岁 22/30；便利/非概率样本，**不能外推为全国青年**。

## 一、客户证据的唯一来源

客户需求、痛点、功能偏好与付费方式的实证结论**只能来自问卷**。以下不得充当客户证据：访谈、社交平台评论、团队成员个人经历、公开市场总量、自动化测试、模拟数据、AI 生成画像。公开资料只用于行业背景。

## 三、隐私与数据最小化

1. 原始 XLSX **不提交**，也不写入项目书、README 或任何 Git 提交。
2. 分析数据删除以下字段：电子邮件、名称、语言、精确开始/完成时间；只保留日期与时长。
3. 问卷没有自由文本；Q5/Q6/Q9 为标准化多选，不存在开放题原文泄露问题。
4. 只能报告汇总值；不得尝试从 R01—R30 反推个人。
5. 年龄分段（含 4 条 `<18`）只作样本构成描述，不用于单独画像或分层结论。
6. 多选题百分比分母为有效答卷数（30），各选项之和可超过 100%；单选题分母为该题有效回答数；单选题的分组合计必须等于该题有效回答数（见 `report.md` 的“分组口径”，Q10 五组之和为 30/30）。

## 四、清洗与统计口径（脚本强制）

| 场景 | 口径 |
| --- | --- |
| 多选题 | 按分号拆分；百分比分母 = 有效答卷数；报告平均选择项数 |
| “无”选项 | `以上皆无/以上均没有/没有明显影响/没有遇到相关问题/目前的方法已经足够好/没有明显担忧/以上均没有明显吸引力` 为互斥项；与其他选项同时出现时，剔除该“无”选项、保留其他选择并记录（本轮 2 处，均来自 R11） |
| 单选题 | 百分比分母 = 该题有效回答数；有 `groups` 的题在报告中给出分组合计，合计必须等于有效回答数 |
| 缺失 | 10 题均无缺失；如未来出现缺失，按题分母计算并在报告标注 |
| 时长 | `完成时间 − 开始时间`（秒）；**不设 60 秒剔除门槛**（实际表单 10 题、以点选为主，最快 21 秒）；<60 秒只做敏感性分析 |
| 重复 | 团队口径为 30 位独立受访者，不做身份去重；导出件无应答编号，`duplicate_key` 为空，报告不按编号去重 |
| 选项校验 | 选项不在 schema 清单内即停止，不猜测；选项清单由导出件取值重建，未出现的选项无法确认 |
| 无效答卷 | 本轮无剔除；如未来剔除，必须记录原因与数量，不得为提高样本量而放宽 |

## 五、结论边界

- 只能写“在这批受访者中……”；必须同时给出 n/N、分母、采集日期与抽样限制。
- 样本量口径为 30 位独立受访者（n=30），但仍是便利/非概率样本，不是全国样本；不得外推为全国青年比例。
- 自报试用意愿不等于实际使用；付费方式偏好不等于具体价格或购买转化。
- 不把样本比例填入市场漏斗；不把“任何付费形式 26.7%”当成付费率或收入。
- 不把“跨城观演 30%”当成全国跨城观演率；不把它当成目标市场规模。

## 六、复现流程

```powershell
# 1. 从原始 XLSX 生成脱敏分析数据（原始文件只读，不入库）
python docs/_work/survey/analysis/import_xlsx.py --input "<原始 XLSX 路径>"
# 2. 生成统计表
pnpm survey:report
# 3. 检查 stats 与 findings 是否一致；报告头部的 SHA-256 应指向同一份原始 XLSX
```

`import_xlsx.py` 需要 openpyxl；本轮使用随附 Python 运行。若原始导出件不是同一结构，脚本会停止并报错，不做猜测。
