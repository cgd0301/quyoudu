1. 目标人群里，"跨城观演"与"多笔分散付款"是否常见（Q1、Q2、Q4）。

3. 现在用什么办法解决（Q8），以及能否接受"暂无法判断"这种保守输出（Q10）。
4. 使用意愿（Q11）与自报付费区间（Q12），以及用银行类工具时的顾虑（Q13）。

## 三、发放前必须确认的三件事

1. 首屏写清用途、匿名性、可不答任何题、随时退出；不收集姓名/手机号/邮箱/学号/账户信息。
2. Q9 为注意力检查题，题干已写明"请选择比较同意（4 分）"，用于清洗。
3. 平台需导出 CSV 且包含 `meta_respondent_id`、`meta_submitted_at`、`meta_duration_seconds` 三列，否则脚本无法去重与判时长。

## 四、发放后的流程

1. 导出 **XLSX 或 UTF-8 CSV**（不要用 Excel 的旧版 CSV 导出）→ 先运行 `pnpm survey:intake --input <导出件>` 检查编码与字段。
2. 检查通过后，把去标识化答卷放到 `docs/_work/survey/raw/responses.csv`（不入库）；在 `raw/metadata.json` 记录 `data_version`、采集起止日期、渠道、回收量、剔除量。
3. 运行 `pnpm survey:report`，得到 `docs/_work/survey/report.md`；若报告为“阻塞”，按报告中的恢复步骤重新导出，不得手工补数字。
4. 把 `report.md` 的有效样本量、各题分布与"不能支持的结论"抄进项目书对应章节；**不得**把自报意愿写成实际使用。

## 五、本轮明确不做

- 不做访谈、不做社群评论抓取、不做用户日志采集；
- 不用任何 AI 生成内容代替作答；
- 不在没有真实答卷时给出任何百分比、均值或相关性。
