# 市场与商业数据溯源台账（v4，2026-10-18）

> **用途**：正式参赛项目书、作品概述、产品建议与任何面向评委的材料中，每一个市场与商业数字都必须能在本台账里查到编号、来源、公式、口径与放行状态。
> **配套文件**：参数 `docs/_work/business_model.params.json`（version 2）、人读版 `docs/_work/business_model.md`、机器可读 `book/data/model/business_model.json`、独立复算 `docs/_work/evidence/recompute_business_numbers.md`、问卷统计 `docs/_work/survey/report.md`、问卷发现 `docs/_work/survey/findings.md`、组合审计 `docs/_work/final_submission_audit.md`。
> **本轮变更**：①删除 27 组市场漏斗情景、27 组单位经济情景、单次成本区间、汇率与 token 取值区间（见第 3 节）；②新增 S01—S20：早前 CSV 阻塞（S01—S08）+ XLSX 可读后的 30 条样本内统计（S09—S20）。客户需求部分支持，价格/收入/单位经济仍无证据。

## 0. 使用规则

### 0.1 数据类型（只有五类）

| 类型 | 定义 | 允许的用法 |
| --- | --- | --- |
| 原始事实 | 能在官方统计、政府公报、监管机构或企业官方页面找到原文 | 可直接作事实陈述，须写来源、单位、时点 |
| 派生计算 | 由已核验原始事实按公开公式算出，任何人可复算 | 可作事实陈述，须写公式、单位与取整规则 |
| 有依据的估计 | 有明确来源、方法、适用范围与不确定性的估算 | 只能按证据强度限定措辞，不得写成精确事实 |
| 未经验证的假设 | 没有真实数据支持 | 只能作为研究问题登记，不得作为市场或经营参数 |
| 纯演示参数 | 仅用于展示公式运行的数值 | 只能放在明确隔离的"公式演示"部分，不得进入摘要与结论 |

### 0.2 核验状态

- **已核实**：已打开原始页面（官方统计、政府公报或官方定价页），数字与台账一致；派生值另有独立复算记录。
- **部分核实**：取得了转述或二手材料，未取得原始数据库／原始文件，结论限制在转述可支持的范围。
- **无法核实**：找不到可引用的原文，不得进入正式结论。
- **已删除**：本轮从正式材料中移除的数字或取值区间。
- **研究设计参数**：项目自身的计划取值（如问卷目标样本量），不是市场数据。
- **待人工确认**：该计划取值需要团队确认后才能对外表述。

### 0.3 放行规则

1. 只有"原始事实"与"派生计算"可以进入正文事实陈述；"有依据的估计"须限定范围；其余三类不得进入正文结论。
2. 正文中的数字必须来自 `book/data` 的占位符或本台账登记的数值，不得手写。
3. 新增任何市场或商业数字，先在本台账登记编号，再写入正文；未登记的数字不得进入成稿。
4. 计算可复现 ≠ 输入有依据；来源真实 ≠ 结论成立。四个层级（计算正确、数据有来源、参数适用、结论成立）必须分别判断。

## 8. 维护规则

1. 新增市场或商业数字：先在本台账登记 D 编号、来源、公式与适用边界，再写入正文；无编号不得进入成稿。
