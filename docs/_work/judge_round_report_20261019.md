## 2 往届案例与"智享账单"对标结论

### 2.1 四个官方展示作品（逐页打开，只能读到摘要级信息）

四个页面（首发财智星 id=110、青葵宝 id=122、兴农"小金通" id=117、AI 绿鉴 id=127）结构完全一致：
标题 + 封面海报 + **一段 100—200 字摘要** +（部分附视频）；**无附件、无章节、无奖项字段**。
因此：**官方展示 ≠ 获奖**，也**不是完整项目书**，本稿只比较摘要级信息。

| 作品 | 摘要能读到的关键内容 | 对本项目的可迁移方法 |
| --- | --- | --- |
| 首发财智星 | "私人财务管家"策划书章节清单（概述／市场／功能／盈利／营销／财务／团队／发展／风险），**全文无任何数字**，且与标题"小模型+大模型"不一致 | 章节清单式写法会使摘要失去信息量，本稿拒绝照抄 |
| 青葵宝 | "**家长代持**账户模式，无缝对接工行低风险基金，1 元起投、收益可视"；"成长守护"风控引擎融合 RBAC 与 ABAC；1.8 亿 K12 学生 | 把账户与申购链条写进方案核心，与趣有度边界**方向相反** |
| 兴农"小金通" | "一底座／三层架构／四机制／**七大模块**"（只给数量），商业模式"多层收费、数据增值、合作共赢" | 唯一给出商业模式措辞的页面；结构计数不等于可核验证据 |
| AI 绿鉴 | 五个模块**名称** + "一站式闭环"定位（四篇中最具体） | 模块写具体才有信息量；但全篇无测试、无准确率、无成本 |

**共性（是本轮最重要的发现）**：技术标签前置到标题、正文只重复一次；数字只有"规模痛点"与"结构计数"两种用途；**四篇都没有可验证的效果指标**；商业与风险披露极不对称。
→ 结论：官方展示页本身**无法支撑任何主张的核实**。趣有度因此刻意反向处理：在正文给出判定对象（每个付款日）、判定口径（D05／D34／D36）与可复算证据（向量编号、导出结果），而不是只给模块名称与主张。
