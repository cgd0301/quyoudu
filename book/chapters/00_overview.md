# 项目摘要

趣有度是面向青年大额、多笔消费的**资金安排与方案比较工具**：用户说清买什么、从哪出发、预算多少、何时有钱到账，系统把门票、交通、住宿等费用按付款日期排成资金时间轴，逐个节点判断"付款当天是否付得起"，在用户给出的完整消费组合中排除不可行方案并排序，确认后才写入正式安排。选题按第十七届"工行杯"青年群体服务方向组织。

它回答的不是"钱花到哪了"，而是**带时点的可行性**：同一笔钱既被当生活费又要拿去付款时，余额看着够、实际不够；逐项挑最低价拼起来，也可能违反相容性约束或整体超预算。趣有度把现金拆成保护性预留与本目标分配，只有未分配资金能支付未覆盖的支出；预计收入不提前到账、未知金额不按 0 处理、依据不足时输出"暂无法完整判断"。

当前交付：确定性引擎已实现，四页原型界面已接入主线；与独立参考实现逐检查点对拍差异 0；端到端 17 条通过，但 UI 层 21 条子用例中 13 条覆盖、3 条部分覆盖、5 条未覆盖，界面不计为整体通过。30 位受访者（便利样本）支持样本内需求，但没有价格与真实使用数据。

市场与商业仍有未知：缺少目标人群年龄结构与跨城观演比例，潜在市场规模无法给出可验证数值；三条商业路径都还是候选，没有合作、试点客户或收入。下一步是补齐高风险 UI 用例、验证用户能否独立完成一次规划任务，并用真实价格点测试付费意愿。
